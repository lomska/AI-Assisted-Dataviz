# AI-Assisted Dataviz

Analytical projects and data visualizations made with AI assistance. Each project lives in its own folder and is published with GitHub Pages.

**Live site:** https://lomska.github.io/AI-Assisted-Dataviz/

## Projects

| Project | What it shows | Data |
|---|---|---|
| [Peaks and Plateaus: Europe’s Foreign Tourism Rhythms](https://lomska.github.io/AI-Assisted-Dataviz/EUForeignTourismRhythms/) ([folder](EUForeignTourismRhythms/)) | How many months each European region needs to reach 75% of its foreign nights, five seasonal patterns, and whether foreign guests sharpen or smooth the year. | Eurostat, 2025 |

Each project folder holds its page (`index.html`), the notebooks behind it and its data.
